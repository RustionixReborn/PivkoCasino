# 🍺 Пивко Казино

Шуточное казино с мини-играми, рублями и шутками про пиво.

## Игры
- ⛏️ Пивной рудник (мин. 250 ₽)
- ⛳ Мини-гольф в кружку (мин. 250 ₽)
- 🔻 Пивной Плонко (мин. 500 ₽; множители разбросаны от 0.5× до 144×, шарики-трапеции)
- 🥁 Барабан фортуны (мин. 250 ₽)
- 📈 Пенный краш (мин. 250 ₽, раннер: успей забрать до обвала)
- 🍺 Налей-ка (бесплатно: +10 / +5 / +2 / −3 ₽)

Любая игра: выбери готовую ставку **или введи свою сумму** (поле «своя ставка»).
Все игры — как настоящее казино (house edge 8–11%), на дистанции дом в плюсе. 😄

## Вход
При заходе сайт просит **пивное кодовое слово** (ключ аккаунта).
- После успешного входа ключ **запоминается** в браузере — в следующий раз вход автоматический.
- Если сохранённый ключ стал неверным — сайт вернёт на экран входа.
- Выход (кнопка 🚪) очищает ключ и возвращает на логин.
