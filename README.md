# 🍺 Пивко Казино

Шуточное казино с мини-играми, рублями и шутками про пиво.
Статический сайт (HTML/CSS/JS) — работает на **GitHub Pages** и локально.

## Игры
- ⛏️ Пивной рудник (мин. 250 ₽)
- ⛳ Мини-гольф в кружку (мин. 250 ₽)
- 🔻 Пивной Плонко (мин. 500 ₽; множители разбросаны от 0.5× до 144×, шарики-трапеции)
- 🥁 Барабан фортуны (мин. 250 ₽)
- 📈 Пенный краш (мин. 250 ₽, раннер: успей забрать до обвала)
- 🍺 Налей-ка (бесплатно: +10 / +5 / +2 / −3 ₽)

Любая игра: выбери готовую ставку **или введи свою сумму** (поле «своя ставка»).
Все игры — как настоящее казино (house edge 8–11%), на дистанции дом в плюсе. 😄

## Вход
При заходе сайт просит **пивное кодовое слово** (ключ аккаунта).
- После успешного входа ключ **запоминается** в браузере — в следующий раз вход автоматический.
- Если сохранённый ключ стал неверным — сайт вернёт на экран входа.
- Выход (кнопка 🚪) очищает ключ и возвращает на логин.

Тестовые аккаунты (в базе):
| Ник | Ключ |
|---|---|
| `admin` | `пивко2026` |
| `boris` | `boris-pivo` |
| `genka` | `genka228` |

Статистика хранится в **Firebase Realtime Database** под `users/<ник>/`.
Кнопка ⚙️ (админка) доступна пользователю `admin`.

## Как добавить юзера (3 способа)

### 1. Админка на сайте (проще всего)
1. Войди под `admin` (ключ `пивко2026`).
2. Нажми ⚙️ в шапке.
3. Введи ник + ключ + стартовый баланс → «Создать аккаунт».
4. Там же можно удалить любого юзера.

### 2. Скрипт add-user.js
```bash
node add-user.js <ник> <ключ> [баланс]
# пример:
node add-user.js petr pivo3000 5000
```

### 3. Вручную в консоли Firebase
Realtime Database → создать `users/<ник>/` с полями:
```json
{
  "key": "твой-секретный-ключ",
  "balance": 1000,
  "gains": 0, "games": 0, "maxWin": 0, "luck": 0, "sound": true
}
```

## Публикация на GitHub Pages
1. Создай репозиторий, загрузи папку.
2. **Settings → Pages → Deploy from branch `main` / root → Save**.
3. Сайт на `https://<ник>.github.io/<репо>/`.

> ⚠️ Секрет базы (`js/firebase.js`) виден всем на GitHub Pages. Владелец знает. Если базу скомпрометируют — пересоздай ключи и правила в консоли Firebase.
